# 颜色掩码视差 Shader 设计规格（2026-08-11）

> 状态：已批准设计。本文定义 URP 2D 下「颜色掩码视差」（Color Mask Parallax）Shader 的目标设计，是后续实现计划与实现的规格依据。
>
> **明确声明：本设计仅创建设计文档；不实现 Shader、不修改任何 Unity 资产或代码。采用方案 A（单次主纹理采样 + 按颜色权重 smoothstep 羽化选偏移）；不做多背景采样、不改相机、不增加复杂交互。**

---

## 1. 目标与核心不变式

### 1.1 目标

在一张主背景纹理上实现伪 3D 视差：根据鼠标相对屏幕中心的二维偏移，让控制贴图中的绿色区域（前景）与红色区域（中景）以不同位移量移动，透明/未标记区域（后景）保持不动。全部逻辑在 ShaderLab 内完成，材质面板可调，不触碰相机与场景对象。

### 1.2 核心不变式（已确认）

1. 技术栈：URP 2D 渲染管线，ShaderLab 编写；目标平台以桌面（鼠标输入）为准。
2. 输入：一张主背景纹理 + 一张控制贴图（绿色=前景、红色=中景、透明/未标记=后景）；控制贴图中红绿目前不重叠。
3. 方案 A：对主背景纹理只采样一次。由颜色原始权重（§2.2 公式）经 smoothstep 羽化并与后景权重重新归一化后，在三个位移之间插值，再据此对采样 UV 施加偏移。
4. 运行时位移来源：鼠标相对屏幕中心的二维偏移，换算为 UV 空间的位移量。
5. 材质面板暴露三个可调参数：`Green Parallax`、`Red Parallax` 两个独立位移滑块（绿通常大于红），以及 `Feather` 层权重过渡滑块（范围 0~0.5，默认 0.1）。
6. 不做多背景采样、不修改相机、不引入交互脚本以外的输入管线；只依赖 Shader 的屏幕/鼠标信息通道。
7. 控制贴图导入与采样固定为 Bilinear（非 Point）+ Clamp；羽化依赖该过滤在颜色层边界产生的插值带。

## 2. 颜色权重定义与归一化

### 2.1 控制贴图导入与采样设置

- 控制贴图导入与采样固定为 Bilinear（非 Point）过滤 + Clamp Wrap Mode（见 §1.2 不变式 7）。
- Feather 的空间过渡带依赖 Bilinear 在红/绿/透明边界产生的插值带；若使用 Point 过滤，该插值带消失，Feather 退化为不可见的硬边切换。

### 2.2 原始权重公式（可实现定义）

对每个片元，控制贴图采样结果为 `(r, g, b, a)`，原始权重定义如下：

- `rawGreen = saturate(g - max(r, b)) * a`
- `rawRed = saturate(r - max(g, b)) * a`
- `rawBg = max(0, 1 - rawGreen - rawRed)`

期望行为：

- 纯绿（g 高、r/b 低、a=1）：`rawGreen = 1`、`rawRed = 0`、`rawBg = 0` → 前景。
- 纯红（r 高、g/b 低、a=1）：`rawRed = 1`、`rawGreen = 0`、`rawBg = 0` → 中景。
- 透明（a=0）：`rawGreen = rawRed = 0`、`rawBg = 1` → 后景。
- 白/灰（r≈g≈b、a=1）：两个颜色权重均趋近 0，`rawBg` 主导 → 后景。

### 2.3 羽化与重新归一化（实现顺序）

1. 对红/绿**原始**层权重执行 smoothstep：`fG = smoothstep(0, Feather, rawGreen)`、`fR = smoothstep(0, Feather, rawRed)`。
2. 后景权重取 `fBg = max(0, 1 - fG - fR)`。
3. 三层重新归一化，保证权重和为 1：`wG = fG / (fG + fR + fBg)`，`wR`、`wBg` 同理。**归一化必须发生在 smoothstep 之后**：这样同一像素不会同时获得满幅度的红、绿位移，红绿 offset 绝不会相加放大。
4. 零分母安全回退：当 `fG + fR + fBg = 0` 时，回退为 `wBg = 1`、`wG = wR = 0`（后景）。
5. 最终 UV 偏移 = `wG × greenOffset + wR × redOffset + wBg × (0, 0)`；后景不移动。

Feather 说明：

- `Feather` 是**层权重过渡强度**（在归一化前的权重轴上，0→1 过渡的宽度），范围 0~0.5、默认 0.1；值为 0 时退化为硬边选择。
- 空间上的可见过渡宽度仍取决于控制贴图纹理分辨率与 Bilinear 过滤的插值带；调大 `Feather` 不会把过渡带扩展到超过 Bilinear 可插值的纹素范围。

## 3. 输入方式与符号约定

### 3.1 鼠标屏幕坐标输入

- 运行时由（后续实现阶段的）轻量脚本在 Update 中读取 `Input.mousePosition`，计算相对屏幕中心的归一化偏移，并通过 Shader 属性传入；Shader 本身不轮询输入。
- 归一化方式：`鼠标屏幕坐标 − (屏幕宽/2, 屏幕高/2)` 后除以屏幕半宽/半高，得到约 −1~1 的二维偏移 `(dx, dy)`；屏幕中心为 (0, 0)。
- 属性类型为二维向量，材质面板不可见（仅脚本写入）。

### 3.2 UV 偏移符号约定

- 采样 UV 取**负**偏移，公式必须带负号：
  `greenOffset = -(dx, dy) × Green Parallax`，`redOffset = -(dx, dy) × Red Parallax`。
- 效果：`dx > 0`（鼠标在屏幕中心右侧）时采样 UV 向 −U 方向偏移，画面内容向左移动；`dy > 0`（鼠标在中心上方）时采样 UV 向 −V 方向偏移，画面内容向下移动。形成「镜头右/上、内容左/下后退」的视差。
- 红/绿层方向一致，仅位移幅度不同，绿通常大于红。
- 符号约定全项目统一，供实现阶段直接套用；若反方向更符合预期，仅在 Shader 内对偏移取负，不改脚本输入。

### 3.3 透明/控制贴图边缘行为

- 控制贴图导入与采样固定为 Bilinear + Clamp（见 §2.1）；Clamp 避免边缘镜像污染权重。
- 未标记（透明或接近无色）区域：`rawBg` 主导，UV 偏移趋近 0，后景静止。
- 主纹理越界：UV 位移后在边缘产生的采样越界行为遵循主纹理的 Wrap Mode（默认建议 Clamp），不额外做边界特判。
- 屏幕未覆盖区域仍按同一规则采样；该区域若未标记则始终静止，可作「后景不移动」的直观验收点。

## 4. 材质面板参数（初始建议值）

| 参数 | 类型 | 范围建议 | 初始值 | 说明 |
| --- | --- | --- | --- | --- |
| `Green Parallax` | Float | 0.0~0.1 | 0.03 | 前景位移量，通常大于 `Red Parallax` |
| `Red Parallax` | Float | 0.0~0.1 | 0.015 | 中景位移量 |
| `Feather` | Float | 0.0~0.5 | 0.1 | 层权重过渡强度（见 §2.3） |
| 鼠标偏移 | Vector | 脚本写入 | — | 运行时输入，材质面板隐藏 |

参数含义：

- `Green Parallax`：控制贴图绿色区域相对鼠标偏移的位移倍数，数值越大前景移动越明显。
- `Red Parallax`：红色区域（中景）的位移倍数，默认约为绿色的一半。
- `Feather`：层权重过渡强度，仅影响红/绿权重在权重轴上 0→1 过渡的宽度，不改变位移方向与幅度；空间可见过渡宽度由控制图分辨率与 Bilinear 过滤决定（见 §2.3）。

## 5. 验收场景

1. **后景静止**：鼠标移动到屏幕任意位置，控制贴图透明/未标记区域的主纹理内容完全不移动。
2. **前景/中景分层**：鼠标从屏幕中心向右侧移动，绿色区域向左位移量明显大于红色区域，两层边缘相对错开，形成前后层次。
3. **羽化过渡**：`Feather` 从 0 调至 0.5，红/绿层边缘从硬边切换变为柔和过渡，无撕裂或跳变；且过渡空间宽度不超出控制图 Bilinear 插值带。
4. **红绿不重叠前提**：控制贴图红绿区域不重叠时，位移表现为两层的简单叠加，无第三层伪影。
5. **中心零位移**：鼠标位于屏幕中心时（`dx = dy = 0`），全画面无任何偏移，与未应用效果时一致。

## 6. 已知限制

1. 控制贴图红绿区域一旦重叠，重叠像素的绿/红权重同时偏高，归一化后位移为两者加权平均，会出现介于两层之间的「折中位移」；当前需求确认红绿不重叠，故不处理重叠特例。
2. 方案 A 每片元只采样一次主纹理，位移在采样前完成，无法产生真正的景深/遮挡关系；层间交叉处的视觉正确性由美术在控制贴图中预留不重叠区域保证。
3. 位移仅由鼠标偏移驱动，不包含惯性、缓动或时间动画；移动的平滑感依赖外部脚本对输入做插值（本设计不包含）。
4. 仅适配桌面鼠标输入；触屏/移动端无鼠标输入通道，需要额外输入源（本设计不覆盖）。
5. 后景不移动意味着画面存在「不动层」，在极端视差幅度下可能与移动层产生明显分离；建议 `Green Parallax` 不超过 0.1，超出时需重新评估视觉质量。
6. 单采样边缘伪影：采样 UV 位移后，主背景与控制贴图边缘附近会产生边缘拉伸或空洞伪影，位移越大越明显；美术应在主背景和控制贴图边缘预留不小于最大位移量的安全余量，避免内容贴边。
