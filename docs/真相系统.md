T01｜《前房客的日记》残页

获取方式：链1（沉默者日记）第5阶段调查房间

道具外观：

一本黑色硬皮笔记本，封面没有任何文字或标记。皮质封面严重磨损，边角已经开裂，露出内衬的纸板。书脊处的胶水已经干裂，轻轻一碰就有纸页脱落。大部分纸页被撕掉了，只剩下中间大约十几页还留着。纸页边缘呈不规则的锯齿状，像是被匆忙扯掉的。纸面泛黄，有些地方有水渍或深褐色的污渍。字迹从钢笔墨水写成，越往后笔画越潦草，到后半部分几乎难以辨认。

可读内容：

…第六天。他们说我是安全的。但安全这个词我已经不记得它是什么意思了。我记得它的发音，记得怎么写，但它对应不上任何感觉。

…第十一天。窗外的树和昨天的树是同一棵树吗。我盯着它看了三个小时。它没有动。没有风。但它的影子在下午三点十七分的时候朝向了错误的方向。不是东西方向的问题，是它指向了一个不存在的位置。我不知道为什么我在意这个。

…第十九天。同住的那个人问我叫什么。我告诉了他一个名字。他说那不是我的名字。我告诉他那就是我的名字。他没有再反驳。为什么他不再反驳了。我应该记得我的名字。我记得我记得我记得我记得我记得我记得

…第二十四天。今天我发现我可以在脑子里同时想两件完全不同的事。这感觉不对。人一次只能想一件事。但我可以。我在数天花板上的裂缝，同时在想我母亲的葬礼，同时在想门口那双鞋的摆放方式，同时在想一个我没有去过的城市的街道布局。四件事。同时。这不是我的能力。这是别的东西在教我怎么用我的脑子。

…第三十天。我决定离开了。不是去别的地方，就是离开。我知道那扇门通向哪里——我住进来第一天就知道了，只是那时候我选择不走过去。现在我觉得是时候了。他们不会找我。他们不会记得我。我也一样。

最后一页只有一行字，写在右下角，字迹几乎不可见：

“它一直都在。不是从外面来的。是从下面。”

发现场景：

你站在XXX空荡荡的房间中央。床铺整齐得不像有人睡过——被子叠成了完美的直角。枕头中央有一个轻微的凹痕，像是有人长时间躺在上面的印记，但触感是冷的。笔记本放在枕头正中央，像是一件被刻意留下的遗物。当你拿起它时，你注意到床头柜上还有一样东西——一支墨水已经干涸的钢笔，笔尖朝向北方。

T03｜《研究所的录音带》

获取方式：D30（逃离者）选择收留 + 追问 + 需要【教师】在场

道具外观：

一盘标准尺寸的盒式录音带。外壳为深灰色，正面贴着一张白色标签纸，上面用黑色马克笔写着“备用-勿动”。写字的人笔迹极快，“勿”字的两个笔画叠在了一起。标签纸边缘已经卷起、泛黄，有一角翘了起来。磁带外壳有细密的裂痕，像是被摔过。打开盒子时能闻到轻微的塑料老化气味。磁带本身看起来还能播放，但带子已经有些松弛了。

转录文本：

\[以下内容由XXX（教师）根据录音内容转录。录音质量较差，背景中有持续的噪音干扰，部分内容难以分辨。]

…不是我在说话。是它在通过我在说话。那台机器——发射器——他们管它叫“天线阵列”——但那个东西不是天线。天线是接收信号的。那个东西是发射的。它在播放。一直在播放。从一开始就在播放。而我们误以为那是信号。那从来就不是信号，那是——

\[录音出现约五秒的高频噪音，听不清内容]

——他们以为可以解码。解码？你无法解码一个一直在变化的东西。你试图捕捉它的时候它就已经不是它了。就像——就像你看着一面镜子想看清镜子本身是什么——你只能看到反射。你不知道镜子是什么。你只知道反射里有什么。而我们一直在研究反射。研究了二十多年。研究的是我们自己的影子。

\[沉默约八秒]

我最后一次看到那台机器的时候，它亮着灯。机器不应该亮灯的。它不是那种需要亮灯的东西。但它在亮。它在呼吸。它在——

\[录音中断约两秒，然后有急促的呼吸声]

我得走了。我不能再告诉别人这件事了。每多一个人知道，就会多一个“反射”。他们已经够多了。如果你听到这段录音——不要试图找到我。也不要试图找到那台机器。你唯一能做的，就是忘掉你听到了这段录音。

\[录音结束前的最后两秒，有一个极轻的声音，像是某人在重复一个词。XXX表示无法确认词的内容。]

转录者备注（XXX手写） ：

磁带全长约11分钟。前7分钟内容混乱，包含大量无意义的重复句，无法转录。以上是从第7分钟开始到第11分钟结束的内容。录音的后半段说话者的声音明显比前半段更清晰——像是受到了某种影响，从混乱中“清醒”了，但那种清醒本身可能也是一种异常。磁带盒的标签纸背面有一行用铅笔写的字，很淡：

“如果他真的不想让人找到他，为什么要录音？”

这个问题我现在还没有答案。也许答案就在那丢失的前7分钟里。

T05｜《错位的旧照片》

获取方式：D05（迷路的老人）收留过夜

道具外观：

一张彩色照片，表面覆盖着一层泛黄的塑料膜。照片的边角有折痕，其中一角曾经被撕掉，又用透明胶带粘了回来。照片中是一群人在一家旅馆的门口合影——大约十几个人，穿着明显属于不同年代的衣服：前排有人穿着1970年代的格子衬衫，有人穿着1980年代的皮夹克，后排有人穿着更近期的深色卫衣。拍摄时间看起来不像是在同一年代。照片的构图不整齐，像是一张抓拍，所有人的视线都落在不同的方向，没有一个人在看你。

可读内容：

照片本身没有文字，但照片背面有人用深色墨水笔写了几个字：

“这家店——门口总是有人。但我每次来都看不到他们在里面。”

字迹很小，像是随手写的，有些潦草。同一行字的旁边，还有一个更浅的铅笔字迹：

“你说得对。因为它不是给人住的。”

这两种笔迹看起来像是来自两个不同的时代——墨水的颜色不同，书写的工具不同。但没有日期。无法判断谁先谁后。

发现场景：

老人没有留下姓名。他在旅馆住了一晚，第二天清晨，你敲他的门想叫他吃早饭时，房间已经空了。被子叠得整整齐齐，枕头上有一些银灰色的头发。照片就放在枕头上。照片边缘有一小块暗红色污渍，不像血迹，更像某种染料或陈年的墨水。门没有锁。走廊里没有人。你站在门口不知道该不该把照片收起来。最后你收了。

T06｜《侵蚀传播路径记录》

获取方式：链6（墙里的日记本）第5阶段完整完成 + 需要【前员工】在场 + 旅馆已解锁3楼

道具外观：

一份用铅笔手绘的地图，被仔细地折成四折，塞在一个金属铅笔盒里。铅笔盒生锈严重，打开时发出了刺耳的金属摩擦声。地图本身画在普通的横线笔记本纸上，纸面已经泛黄、变脆。地图描绘的是旅馆及其周边区域，但比例很奇怪——旅馆被画得非常巨大，占据了图纸的大半，而周边的山丘和道路被压缩到边缘。图纸上有大量用铅笔标注的数字和日期，还有一些箭头，指向不同的方向。

可读内容：

地图中央标着“旅馆”两个字，周围画着许多同心圆——不是标准的圆形，而是不规则的波纹，像是手绘的，一边画一边改，有的重叠起来。每个同心圆附近都有日期标注，时间跨度大约在三年左右。最外层的波纹旁边有一行小字，是这份图纸上最好辨认的字迹：

“我画了三年。每次它都会向外扩张一点点。每次扩张——都有人离开。”

地图右上角有另一段文字，字迹明显不同，更小、更谨慎：

“第一次画这张地图的时候，我觉得我在标记它的位置。现在我看着这张纸——我觉得我在标记我自己。”

背面只有一行字，用非常粗的铅笔写的：

“零号点并不在研究所。”

发现场景：

XXX（前员工）在打开306房间的墙板后，从里面的空隙中抽出了一个扁平的金属盒。盒子里除了这份地图，还有几支已经干了的铅笔。在地图边缘有一些空白处，上面能隐约辨认出反复擦除又重写的痕迹——旧的铅笔印已经被橡皮擦得差不多了，但在特定角度下能看到凹陷的压痕，像是有人在写完之后又决定把它擦掉，但铅笔的笔尖留下了一道道极细的刻痕。

T07｜《老经理的笔记》

获取方式：链6（墙里的日记本）第4阶段调查306房间 + 旅馆已解锁3楼

道具外观：

一本深绿色硬皮笔记本，比常见的口袋本略大一些。封面没有标题，只有右下角用金色压印着一个字母——“E”。笔记本的锁扣是坏的，一根旧的皮绳代替了原来的金属扣。纸页的边缘已经泛黄发脆，翻阅时需要格外小心。整本笔记被分成三个部分，用不同颜色的书签带隔开：第一部分大约占了全书的一半，记录密集；第二部分较薄，记录稀疏；第三部分只有三页纸，但上面只剩下一句话。

可读内容：

第一部分·选段（较早期）

…没人告诉我这家旅馆是谁建的。我接手的时候它就是现在的样子。老陈说它至少存在了四十年，但老陈自己也才五十岁。他的说法靠不住。门廊的台阶不是这个年代的石头——它们的磨损程度不对。我找人看过，那人说这石头需要走几百年才能磨成那样。几百年。这家旅馆才多少年？

…今天有几个房客说他们房间的窗户对着一条街道。那条街道在三楼。但楼下是空地。我问他们是哪一扇窗，他们说“东面那扇”。东面的窗外是山。没有街道。他们坚持说有。我没有反驳。

…地下室的门从来没有打开过。从我来的第一天就是锁着的。前任经理把钥匙交给我时说了一句话：“你需要用的时候它会自己开的。”我不知道这是什么意思。

第二部分·选段（较晚期）

…我开始记不清一些事情。比如今天是星期几。比如这个房间是不是我自己的。我站在门口看了很久才确定这是我的房间——因为桌子上有我的笔。这是我唯一能确认的方式。我的笔在这里，所以这是属于我的空间。

…东面的窗户。我刚才又看了。窗外是山。没有街道。但那个房客坚持说有街道。现在我看着他描述的“街道”方向，我开始怀疑——也许我看到的是不一样的东西。也许他看到的是别的什么。也许那扇窗户在不同的人眼里通往不同的地方。

…老陈走了。他没有说再见。他在桌子上留了一个纸条：“我知道那扇门通向哪里。你别跟过来。”

第三部分（只有三页，前两页被撕掉了，只剩第三页）

“这家旅馆没有地下室。”

发现场景：

306房间位于三楼的尽端。它比别的房间稍大一些，但窗户的朝向很特别——朝东，正对着远处的山脊。房间里只有一张床、一张桌子和一把椅子。桌子靠窗摆放，桌面上有被长时间放置物体留下的压痕——一个方形的轮廓，大小与深绿色笔记本一致。你拿起笔记本时，窗外有极短暂的一瞬间变得明亮，像是阳光穿透云层——但抬起头时，窗外的天是阴的。

T08｜《巡逻报告·异常日》
