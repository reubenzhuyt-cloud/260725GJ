# 事件目录

## 编写约定

- 所有消耗/成本统一使用食物或货币，不引入其他资源类型。
- 能力标签（如【医生】）的作用是降低消耗或缓解后果，而非阻止事件触发。
- 描述文本中的 `XXX` 表示运行时选定的房客，由系统在触发时确定。
- 条目中涉及尚未实现的系统（设施耐久、效率、楼层/阻断、天气、探索、线索、完全体伪人、驱逐、房间分配等）时，保留原文措辞，并在该条目标题正下方标注 `> 实现状态：待系统支持`。
